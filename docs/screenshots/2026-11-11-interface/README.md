# Tagcast 1.7.0 interface — 11 November 2026

Ten screenshots supplied by the maintainer. The workspace/sidebar captures show
the 1.7.0 badge. All originals retain their supplied bytes and full 2836 × 1828
frame. No cropping, retouching or generated interface was applied. The website
uses smaller WebP previews linking to these unchanged full-size PNGs.

These illustrate browsing, artist/album pages, image comparison, metadata editing
and review, Now playing, CD and cover views. A visible review is not evidence of
a completed save. Importing these files performed no account writes. Existing
third-party artwork, photographs, TheAudioDB/Discogs credits and LRCLIB attribution
remain visible and belong to their respective owners. Lyrics display does not save text.
The separate [visualization set](../2026-11-11-visualizations/) covers all eight effects.
