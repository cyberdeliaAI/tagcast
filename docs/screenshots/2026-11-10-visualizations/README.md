# Music visualizations — 10 November 2026

Nine original screenshots supplied by the project maintainer from local pre-release
visualization test builds. **The pictured features ship in Tagcast 1.7.0.**
These are test-build captures taken before publication, not captures of the tagged
release binary. They show five effects: Oscilloscope, LED spectrum, Ribbons, Orbit
and Aurora. Four later captures show another track and the lyrics combination.
Neon ring, Starfield, Waterfall and automatic rotation are described in the guide;
they are not demonstrated by these still images.

All nine PNGs retain their supplied bytes, dimensions and full frame. No cropping,
retouching, generated UI or replacement text was applied. The website serves smaller
WebP previews and links to byte-identical full-size PNGs. Track/artist/album names
remain part of the supplied interface. The lyrics capture retains LRCLIB attribution,
Follow and the temporary-display label; displaying lyrics does not save them.
