# Tagcast 0.80.0 screenshots

Five original captures from 23 October 2026 show the current shared interface,
served from the verified macOS Apple Silicon archive. A separate fictional sample
library and local source suggestions are used; these are not a personal iBroadcast
account. Lyrics are original sample text. No music metadata was saved for these
captures, and no external metadata or lyrics provider was contacted.

Personal account names, email addresses and other account details are absent.
Overview was not recaptured; the earlier contributor-redacted Overview remains
unchanged. The browser captures JPEG directly; these files retain those bytes
without cropping, resizing, annotation or pixel edits.
