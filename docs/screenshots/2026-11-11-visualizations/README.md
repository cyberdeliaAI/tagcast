# Music visualizations — 11 November 2026

Nine original screenshots supplied by the maintainer: **all eight visualization
effects**, followed by Aurora with lyrics. These features are included in Tagcast
1.7.0. Every capture shows Freestyler by Bomfunk MC's, from In Stereo.
The capture date does not independently establish which binary was used.

All PNGs preserve the supplied bytes, dimensions and full frame. No cropping,
retouching or replacement text was applied. The website serves responsive WebP
previews linking to byte-identical originals. The lyrics example retains Follow,
LRCLIB attribution and the temporary-display label; displaying text does not save it.
Still images do not demonstrate automatic 30-second rotation.

This set replaces the repeated effect/track examples in the active Wiki and website
galleries. The [10 November archive](../2026-11-10-visualizations/) remains available
as historical documentation.
