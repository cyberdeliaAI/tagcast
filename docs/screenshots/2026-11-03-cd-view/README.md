# Optional CD view — 3 November 2026

Original screenshots supplied by the project maintainer from the local Apple Silicon
CD-view test build based on Tagcast 1.3.0. **The CD option is not included in the
published 1.3.0 downloads.** These images document an unreleased presentation option,
not a new application release.

The two captures show the same track in the standard CD layout and with the lyrics
panel open. The disc is shown partway through its rotation. The ordinary rectangular
album cover remains the default; CD view is optional and remembered locally.

| [cd-view.png](cd-view.png) | `Screenshot 2026-11-03 at 19.33.18.png` | 2752 × 1758 | Optional CD view with album artwork printed on the disc, track information and the existing player controls. |
| [cd-view-lyrics.png](cd-view-lyrics.png) | `Screenshot 2026-11-03 at 19.33.44.png` | 2752 × 1758 | CD view beside LRCLIB lyrics, with the current line highlighted and provider attribution visible. |

The lyrics capture shows LRCLIB line timing, not word timing. The provider attribution
and temporary-display label remain visible. Lyrics shown in the player are not saved
to iBroadcast by opening either view.
